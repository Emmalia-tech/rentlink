# RentLink Ghana

**Find. Verify. Pay. Protect.**

A nationwide digital rental and accommodation platform connecting tenants, landlords, verified agents, and authorized rental regulatory personnel through one trusted digital ecosystem.

## Vision

Make finding and renting accommodation in Ghana easier, safer, and more transparent.

## Core Users

- Tenants
- Landlords
- Verified agents
- Authorized rent control officers
- Platform administrators

## The Rental Journey

**Find -> View -> Rent -> Pay -> Record -> Protect**

## Tech Stack

- **Frontend:** React, TypeScript
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL
- **Version Control:** Git, GitHub

## Project Status

Under development.

Building in phases:
1. Authentication & user roles
2. Property listings & search
3. Verification
4. Communication
5. Rental records & complaints
6. Authorized administrative workflows

## Important Note on Verification

Verification statuses displayed on RentLink indicate what has actually been reviewed or verified. They are **not presented as a legal determination** unless made by the appropriate authorized authority.
